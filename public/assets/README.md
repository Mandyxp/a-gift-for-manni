# Personal asset replacement guide

All story content lives in `src/data/config.ts`.

- `letters/`: add `letter-01.jpg`, `letter-02.jpg`, etc. Portrait scans work best.
- `photos/`: add `memory-01.jpg`, `memory-02.jpg`, etc. Any photo count is supported through the config list.
- `audio/`: add `background.mp3`, then set `audio.available` to `true` in the config.
- `textures/`: optional paper textures for future customization.

Missing personal images intentionally render as elegant paper placeholders, so the page remains complete while assets are being prepared.
